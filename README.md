# Proyecto-LP

Este proyecto usará la librería PLY de Python para implementar un analizador léxico, sintáctico y semántico. Este analizador podrá interpretar código perteneciente al lenguaje de programación de Kotlin.

### Librerias necesarias:

- customtkinter==5.2.2
- darkdetect==0.8.0
- DateTime==6.0
- packaging==25.0
- ply==3.11
- pytz==2025.2
- tzdata==2025.2
- zope.interface==8.1.1
